# פילאטיס מזרן – תרגול

כלים ללימוד תרגילי פילאטיס מזרן מתוך חוברת הקורס.

- **`index.html`** – אפליקציית התרגול: כרטיסיות, מבחן ועיון בכל 48 התרגילים. נפתחת ישירות בדפדפן או דרך GitHub Pages.
- **`חוברת-זיכרון.pdf`** – חוברת הזיכרון: תרגום שם, טריק לזיכרון, מוצא, נשימה, דגשים ושרירים לכל תרגיל.

## צפייה באתר
אחרי הפעלת GitHub Pages (Settings ← Pages ← Branch: main), האפליקציה זמינה בכתובת:
`https://<שם-המשתמש>.github.io/<שם-הריפו>/`
